## 刷机/恢复

```bash
adb reboot bootloader
fastboot getvar current-slot
fastboot flash boot boot-sukiSU-<rom>-5.10.256-gki-ge682ed2de56f.img   # 刷入
fastboot reboot
fastboot flash boot derp_stock_boot_backup.img                          # 恢复原厂
```

注意：boot 含各自 ROM 的 ramdisk，**不能跨 ROM 混用**；`fastboot boot` 临时引导本设备忽略；
OTA/重刷 ROM 会覆盖 boot，需重刷。
