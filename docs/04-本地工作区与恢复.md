## 刷机/恢复

```bash
# 进 fastboot
adb reboot bootloader

# 查当前 slot
fastboot getvar current-slot

# 刷入 KSU 内核（刷到当前 slot 的 boot）
fastboot flash boot boot-sukiSU-5.10.256-gki-ge682ed2de56f.img
fastboot reboot

# 恢复原厂 boot（从产物 zip 的 rom_out/boot.img 或 los232/boot.img）
fastboot flash boot rom_out/boot.img
fastboot reboot
```

注意：`fastboot boot` 临时引导在本设备被忽略；每次 OTA/重刷 ROM 会覆盖 boot，需要重刷 KSU 镜像。
