# 术语表

| 术语 | 含义 |
|---|---|
| GKI | Google Generic Kernel Image，通用内核镜像（KMI 冻结、vendor 模块独立编译） |
| KMI | Kernel Module Interface，GKI 内核的模块接口版本（如 android12-5.10） |
| 非 GKI / OSS 内核 | 厂商/社区从源码编译的设备内核（cupid 的高通 SM8450 内核属于此类） |
| 伪 GKI | 版本字符串里带 `gki-` 但内核本体不是 GKI（本项目的核心陷阱） |
| vermagic | 内核/模块的版本魔数串（如 `5.10.256-gki-ge682ed2de56f SMP preempt mod_unload modversions aarch64`），模块加载必须完全一致 |
| CONFIG_MODVERSIONS | 模块符号 CRC 校验（modversions），版本一致之外还要符号 CRC 匹配 |
| LOCALVERSION / LOCALVERSION_AUTO | 内核版本后缀机制；AUTO 会追加 `-g<sha>` 和脏树 `+` |
| LKM | Loadable Kernel Module；KernelSU 的"修补 boot 加载模块"模式（本设备无效） |
| IKCONFIG | 编译进内核的 .config（`/proc/config.gz`），可用 `scripts/extract-ikconfig` 提取 |
| SukiSU Ultra | KernelSU 的 fork，支持非 GKI，分支：main（kprobe）/ builtin（LSM hook + SUSFS） |
| SUSFS | SukiSU/KernelSU 的 root 隐藏内核补丁（sus_mount/sus_path/伪装 uname/cmdline 等） |
| KPM | Kernel Patch Module，KernelPatch 的模块机制（本构建默认关） |
| supercall | SukiSU/KernelSU 与用户态通信的自定义系统调用通道（不是 /dev 节点） |
| magiskboot | Magisk 的 boot 镜像解包/重打包工具 |
| payload-dumper-go | 从 OTA payload.bin 提取分区镜像的工具 |
| AnyKernel3 | 通用内核刷入 zip 模板（本仓库产物为纯 boot.img，未用） |
| KMI 版本 | 内核版本字符串前两段，如 5.10 |
| boot 分区 | cupid 上存放内核+ramdisk 的分区（A/B 有 boot_a/boot_b，无 init_boot） |
| vendor_boot | 存放 vendor 模块、DTB、bootconfig 的分区（刷机时不动它） |
| SPL | Security Patch Level 安全补丁级别 |
