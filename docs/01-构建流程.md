# 构建流程

文件：`.github/workflows/sm8450-sukisu.yml`

## 输入参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `rom_preset` | lineage-23.2 | ROM：lineage-23.2 / aviumui-16.2.1 / derpfest-16.2 / custom |
| `preset` | suki-susfs | 配置预设：suki-susfs（推荐）/ suki-stable / resuki-susfs / custom |
| `rom_url` | 空 | 仅 custom ROM 时填直链 |
| `kernel_commit` | e682ed2de56f... | 内核 commit（一般不改） |
| `root_impl` / `ksu_ref` / `ksu_version` / `susfs` / `ksu_commit` / `build_rekernel_x` | - | [高级] 仅 preset=custom 时生效 |

## 关键流程

1. Checkout 仓库（DerpFest 用 stock_boot）→ 装依赖 / clang r563880c / magiskboot / payload-dumper-go
2. **Resolve ROM preset**：解析 ROM 直链（DerpFest 默认仓库 boot.img.gz，跳过下载）
3. **Resolve build preset**：preset 非 custom 时自动填充技术参数到 GITHUB_ENV
4. 解包原厂 boot → 提取 IKCONFIG 作为构建配置 → 解析 vermagic 设版本字符串
5. **Integrate Root**：sukisu=clone SukiSU-Ultra（susfs 用 builtin@6c13a069）；resuki=完整 clone ReSukiSU（main）
6. 软链 `drivers/kernelsu` → 注入 Makefile/Kconfig；susfs=yes 时打 susfs4ksu（gki-android12-5.10）内核补丁
7. Prepare config：LOCALVERSION=SUFFIX + KSU=y +（susfs=KSU_SUSFS / resuki 无 susfs=KSU_MANUAL_HOOK）
   + full LTO 改 thin LTO（防 OOM）
8. `export LOCALVERSION=""`（抑制 vermagic 的 `+`）→ make Image →（可选）编 ReKernel-X LKM
9. Verify：构建内核 vermagic 精确等于原厂；CONFIG_KSU=y
10. Repack：Image 换入原厂 boot.img → `boot-sukiSU-<rom>-<ver>.img`

## 产物

- `boot-sukiSU-<rom>-<ver>.img`：成品 boot
- `Image`：原始内核 · `rom_out/boot.img`：原厂备份
- `stock.config` / `built.config`：配置对照
- `ReKernel-X-1.5-cupid-5.10.256.zip` + `rekernel_x.ko`：墓碑模块
