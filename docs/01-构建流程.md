# 构建流程（workflow 逐步骤）

文件：`.github/workflows/sm8450-sukisu.yml`

## 输入参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `rom_url` | Princeton 镜像 20260820 nightly 直链 | ROM 包，用于提取 boot.img |
| `kernel_commit` | `e682ed2de56f...` | 内核源码 commit（必须与 ROM 一致） |
| `ksu_ref` | `v4.1.3` | SukiSU 分支/tag（main=开发版，builtin=SUSFS 版） |
| `ksu_version` | `40796` | 强制驱动版本号（与管理器一致） |
| `build_rekernel_x` | `yes` | 编译 ReKernel-X LKM 并打包 |
| `susfs` | `no` | 开启 SUSFS（自动切 builtin + 打补丁） |
| `ksu_commit` | `6c13a069...` | SUSFS 时 pin 的 builtin 提交（v4.1.3 协议匹配） |

## 流程

1. **Free disk space**：清理 runner 磁盘（LTO 构建很占空间）。
2. **Install dependencies**：git/curl/xz/lz4/bc/bison/flex/libssl/libelf 等。
3. **Download clang**：clang-r563880c（clang 21，与 nightly 相同）。来源 GitHub release 镜像，失败可换 googlesource。
4. **Download magiskboot**：从**官方 Magisk APK** 提取 `lib/x86_64/libmagiskboot.so`（静态 ELF，可在 Linux 跑）。不要用第三方 Rust 版（repack 有 ENOENT bug）。
5. **Download payload-dumper-go**：ssut 版 v2.0.2（参数 `-partitions boot -o out zip`）。不要用 xishang0128 版（CLI 不同）。
6. **Download ROM zip**：从 `rom_url` 下载。
7. **Extract boot.img**：payload-dumper-go 只解 boot 分区。
8. **Clone kernel source**：lineage-23.2 浅克隆 + fetch 指定 commit。
9. **Unpack stock boot.img**：magiskboot 解出 kernel/ramdisk；把原厂 boot.img 复制进工作目录（repack 要用）。vbmeta ASN.1 警告无害。
10. **Extract stock version & config**：
    - vermagic 第一个字段 = 版本字符串（如 `5.10.256-gki-ge682ed2de56f`）
    - `scripts/extract-ikconfig` 从原厂内核提取**最终配置**作为构建配置
11. **Integrate SukiSU**：克隆 SukiSU → 软链 `drivers/kernelsu` → 注入 drivers/Makefile + Kconfig → 强制 `KSU_VERSION`（sed 覆盖 Kbuild/Makefile）。`susfs=yes` 时：分支强制 builtin + 克隆 susfs4ksu（gki-android12-5.10）→ 拷贝 fs/*、include/linux/* → `patch -p1` 打 50_add 补丁。
12. **Prepare config**：`LOCALVERSION="$SUFFIX"` + 关 `LOCALVERSION_AUTO` + 开 `KSU` + （susfs 开 `KSU_SUSFS`）+ **full LTO 改 thin LTO**（防 OOM）→ `make olddefconfig`。
13. **Add swap**：runner 自带 /swapfile，先 `swapoff -a` 再重建 8G。
14. **Build kernel**：`export LOCALVERSION=""`（关键！否则 vermagic 多一个 `+`）→ `make Image`。
15. **Build ReKernel-X LKM**（可选）：源码放内核树 `drivers/rekernel_x`（相对 include 依赖）→ `make modules_prepare`（生成 module.lds）→ 用 `vmlinux.symvers` 组装 `Module.symvers` → `make M=... modules` → 校验 ko vermagic == 内核版本。
16. **Verify**：构建内核 vermagic **精确等于**原厂版本；`CONFIG_KSU=y`（susfs 时 `CONFIG_KSU_SUSFS=y`）。
17. **Repack**：把构建的 Image 覆盖 kernel → `magiskboot repack boot.img` → `new-boot.img`。
18. **Upload artifacts**：boot img、Image、原厂 boot、stock/built config、ReKernel-X 模块 zip + ko、构建日志。

## 产物

- `boot-sukiSU-<版本>.img`：直接刷入 boot 分区
- `Image`：原始内核（备用）
- `boot.img`：原厂备份
- `stock.config` / `built.config`：配置对照
- `ReKernel-X-1.5-cupid-5.10.256.zip` + `rekernel_x.ko`：匹配内核的墓碑支持模块
