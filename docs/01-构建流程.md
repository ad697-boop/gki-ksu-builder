# 构建流程（workflow 逐步骤）

文件：`.github/workflows/sm8450-sukisu.yml`

## 输入参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `rom_preset` | `lineage-23.2` | ROM 预设：`lineage-23.2` / `aviumui-16.2.1` / `derpfest-16.2` / `custom` |
| `preset` | `suki-susfs` | 配置预设：`suki-susfs`（推荐）/ `suki-stable` / `resuki-susfs` / `custom`（高级手动） |
| `rom_url` | 空（custom 时必填） | 自定义 ROM 直链；预设会自动覆盖此值 |
| `root_impl` | `sukisu` | [高级] Root 实现（仅 preset=custom 生效） |
| `kernel_commit` | `e682ed2de56f...` | 内核源码 commit（必须与 ROM 一致） |
| `ksu_ref` | `v4.1.3` | [高级] SukiSU/ReSukiSU 分支或 tag（仅 preset=custom 生效） |
| `ksu_version` | `40796` | [高级] 强制驱动版本号（ReSukiSU 留空自动） |
| `build_rekernel_x` | `yes` | [高级] 编译 ReKernel-X LKM |
| `susfs` | `no` | [高级] 开启 SUSFS（仅 preset=custom 生效） |
| `ksu_commit` | `6c13a069...` | [高级] SUSFS 时 pin 的 builtin 提交 |

预设自动填充的配置：

| 预设 | root_impl | ksu_ref | ksu_version | susfs | ksu_commit | ReKernel-X |
|---|---|---|---|---|---|---|
| `suki-susfs`（推荐） | sukisu | v4.1.3 | 40796 | yes | 6c13a069 | yes |
| `suki-stable` | sukisu | v4.1.3 | 40796 | no | - | yes |
| `resuki-susfs` | resuki | main | 自动 | yes | - | yes |
| `custom` | 手动 | 手动 | 手动 | 手动 | 手动 | 手动 |

## 流程

1. **Free disk space**：清理 runner 磁盘（LTO 构建很占空间）。
2. **Install dependencies**：git/curl/xz/lz4/bc/bison/flex/libssl/libelf 等。
3. **Download clang**：clang-r563880c（clang 21，与 nightly 相同）。来源 GitHub release 镜像，失败可换 googlesource。
4. **Download magiskboot**：从**官方 Magisk APK** 提取 `lib/x86_64/libmagiskboot.so`（静态 ELF，可在 Linux 跑）。不要用第三方 Rust 版（repack 有 ENOENT bug）。
5. **Download payload-dumper-go**：ssut 版 v2.0.2（参数 `-partitions boot -o out zip`）。不要用 xishang0128 版（CLI 不同）。
6. **Resolve ROM preset**：按 `rom_preset` 解析最终 `ROM_URL` 与 `ROM_LABEL`。
   - `lineage-23.2` → Princeton 镜像 20260820 nightly 直链
   - `aviumui-16.2.1` → SourceForge `AviumUI-16.2.1-cupid-20260716-Official-GMS.zip` 直链
   - `derpfest-16.2` → 默认使用**仓库内** `stock_boot/derpfest-16.2/boot.img.gz`（原厂 boot 压缩，21.9MB，
     跳过 ROM 下载与 payload 解包）；若填了 `rom_url` 则改为下载完整 ROM
   - `custom` → 使用手动填写的 `rom_url`
   两个预设共用内核 commit `e682ed2de56f`；AviumUI 的 ramdisk 与 LineageOS 不同，
   所以必须用各自 ROM 的 boot.img 重打包（workflow 本身就是这么做的）。
7. **Resolve build preset**：按 `preset` 自动填充 ROOT_IMPL/KSU_REF/KSU_VERSION/SUSFS/KSU_COMMIT/BUILD_REKERNEL_X
   （见上表）；`custom` 时保持手动输入。
8. **Prepare boot.img from repo**（仅 DerpFest 默认模式）：`gunzip -c stock_boot/.../boot.img.gz > rom_out/boot.img`。
9. **Download ROM zip**：从解析后的 `ROM_URL` 下载（DerpFest 仓库模式跳过）。
10. **Extract boot.img**：payload-dumper-go 只解 boot 分区（DerpFest 仓库模式跳过）。
11. **Clone kernel source**：lineage-23.2 浅克隆 + fetch 指定 commit。
12. **Unpack stock boot.img**：magiskboot 解出 kernel/ramdisk；把原厂 boot.img 复制进工作目录（repack 要用）。vbmeta ASN.1 警告无害。
13. **Extract stock version & config**：
    - vermagic 第一个字段 = 版本字符串（如 `5.10.256-gki-ge682ed2de56f`）
    - `scripts/extract-ikconfig` 从原厂内核提取**最终配置**作为构建配置
14. **Integrate Root**：按 `root_impl` 克隆 SukiSU-Ultra 或 ReSukiSU 到 `KernelSU/` → 软链 `drivers/kernelsu` → 注入 drivers/Makefile + Kconfig。
    - sukisu：`susfs=yes` 强制 builtin 分支（自带 SUSFS 驱动代码），可 pin `ksu_commit`（6c13a069）；强制 `KSU_VERSION`（sed）。
    - resuki：完整克隆（Kbuild 要 git commit 数算版本）；`ksu_ref` 默认 main，可填 tag；默认不强制 `KSU_VERSION`（自带公式 30000+commits+700）。
    - 两者 `susfs=yes` 时都克隆 susfs4ksu（gki-android12-5.10）→ 拷贝 fs/*、include/linux/* → `patch -p1` 打 50_add 补丁。
15. **Prepare config**：`LOCALVERSION="$SUFFIX"` + 关 `LOCALVERSION_AUTO` + 开 `KSU` + （susfs 开 `KSU_SUSFS`；resuki 且无 susfs 时开 `KSU_MANUAL_HOOK` 兼容非 GKI）+ **full LTO 改 thin LTO**（防 OOM）→ `make olddefconfig`。
16. **Add swap**：runner 自带 /swapfile，先 `swapoff -a` 再重建 8G。
17. **Build kernel**：`export LOCALVERSION=""`（关键！否则 vermagic 多一个 `+`）→ `make Image`。
18. **Build ReKernel-X LKM**（可选）：源码放内核树 `drivers/rekernel_x`（相对 include 依赖）→ `make modules_prepare`（生成 module.lds）→ 用 `vmlinux.symvers` 组装 `Module.symvers` → `make M=... modules` → 校验 ko vermagic == 内核版本。
19. **Verify**：构建内核 vermagic **精确等于**原厂版本；`CONFIG_KSU=y`（susfs 时 `CONFIG_KSU_SUSFS=y`）。
20. **Repack**：把构建的 Image 覆盖 kernel → `magiskboot repack boot.img` → `new-boot.img` → 命名为 `boot-sukiSU-<rom预设>-<版本>.img`。
21. **Upload artifacts**：boot img、Image、原厂 boot、stock/built config、ReKernel-X 模块 zip + ko、构建日志。

## 产物

- `boot-sukiSU-<rom预设>-<版本>.img`：直接刷入 boot 分区（如 `boot-sukiSU-aviumui-16.2.1-5.10.256-gki-ge682ed2de56f.img`）
- `Image`：原始内核（备用）
- `boot.img`：原厂备份
- `stock.config` / `built.config`：配置对照
- `ReKernel-X-1.5-cupid-5.10.256.zip` + `rekernel_x.ko`：匹配内核的墓碑支持模块
